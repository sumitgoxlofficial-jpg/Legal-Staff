How to use

Choosing trademark classes and NIC codes

Search by what you sell

India follows the Nice Classification: classes 1 to 34 cover goods and 35 to 45 cover services. Search for the product or service in plain words, then open a class to see what it covers and how similar Indian businesses use it.

File where you trade, not everywhere

Each class is a separate application and a separate government fee. File in the classes you use or genuinely plan to use; broad, unused filings invite objections and oppositions. Software products usually need classes 9 and 42; an online store selling your own goods adds class 35.

NIC codes are a different list

The National Industrial Classification (NIC 2008) code describes your business activity for SPICe+, Udyam and GST-linked forms. It has nothing to do with trademark classes. The codes below are four-digit NIC classes; forms may ask for the 2-digit division or the 5-digit sub-class within it.

Frequently asked questions

Which trademark class is a SaaS product in?

Software offered as a service is in class 42. Downloadable software and mobile apps are in class 9. Many SaaS companies file in both, and add class 35 if the product provides business, marketing or marketplace services.

Do I need to file in class 35 for an online store?

Class 35 covers retail and online-store services. If you sell your own products online, file in the goods class for those products (for example class 25 for clothing) and consider class 35 for the store itself, especially if you also sell other brands.

Can one trademark application cover several classes?

Indian law allows a multi-class application, but the official fee is charged per class. Each class is examined for its own goods or services, so the description in each class needs to be accurate.

Is an NIC code the same as a trademark class?

No. NIC 2008 codes classify economic activity for government forms such as SPICe+ and Udyam registration. Trademark classes follow the Nice Classification and decide the scope of your brand protection. You will usually need both.

Are these examples a substitute for a trademark search?

No. They help you understand where your goods and services sit. Before filing, run a search for identical and similar marks in the same and related classes; a professional search also checks phonetic similarity and pending applications.
